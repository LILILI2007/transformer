# ModLingo · 星露谷 mod 翻译工作台

面向普通玩家的 Windows 中文工具。导入星露谷 mod 的标准 i18n 文本，通过自己配置的大模型 API 生成简中初稿，修改并检查后导出翻译包。更新 mod 时复用未变译文，只处理新增和变更内容。

**当前版本：0.1.0 可运行原型。** 只支持平铺的 `i18n/default.json` / `i18n/zh.json`，不支持任意 mod 全量汉化。示例是自创测试素材，不是可加载的游戏 mod。

## 给玩家：如何启动

有便携包时，解压 `release/ModLingo-Windows-x64.zip`，打开其中 `ModLingo/ModLingo.exe`。请保留同文件夹下的 `_internal` 等文件，不能只复制 EXE。

从源码启动需要 Python 3.9 及以上和 Tkinter（官方 Windows Python 安装通常包含），双击根目录 `Start.cmd`，或在项目目录运行：

```powershell
python -m modlingo
```

不需要安装运行时第三方包。没有 API 密钥，也能打开示例、编辑、检查、保存项目和导出；**真实自动翻译需要可用 API 服务**。

## 五步完成一次翻译

1. 点击“导入 mod”，选择直接包含 `manifest.json` 的单个 mod 文件夹。
2. 打开“API 设置”，填写服务地址、模型名称、密钥，可先测试连接。测试也可能计费。
3. 点击“翻译待处理文本”。开始前会展示服务、模型、条目数和字符数。
4. 查看“需要处理”，修正或确认译文。未知复杂语法会跳过；检查失败的译文不能导出。
5. 点击“导出翻译 ZIP”。按包内安装说明，把 `zh.json` 放入原 mod 的 `i18n` 文件夹，先备份已有中文文件。

更新时点击“载入更新”，选同一 `UniqueID` 的新版 mod。未变文本保留，变更项保留旧原文和旧译文供对照，新候选必须确认。

首次配置会发送待译文本、翻译键和相关术语到你选定的服务。解析、编辑、项目保存、导出在本机进行。API 密钥只在本次进程内存中，也可从 `MODLINGO_API_KEY` 环境变量读取，不写进项目和 ZIP。

## 已实现

- 中文图形界面、单 mod 导入、已有中文保留。
- JSONC 注释、尾逗号、UTF-8 BOM 导入；拒绝非字符串值和重复键。
- 大模型接口配置、连接测试、批量翻译、限次重试、停止后续请求。
- 常见占位符和简单对话标记保护；译文结构检查、术语复核提示。
- 人工编辑、原文回退筛选、项目自动保存、打开项目、保存可迁移副本。
- 以 mod `UniqueID` 和翻译键比对更新；删除项归档，未变项不重译。
- 仅翻译文件 ZIP、安装及恢复说明、跳过项报告。

## 当前边界

| 情况 | 处理 |
|---|---|
| 平铺 `i18n/default.json`，可选 `zh.json` | 支持，默认按英语→简中处理 |
| Content Patcher 已通过 i18n 引用的文本 | 在上述布局内支持 |
| `i18n/default/*.json` 分文件布局 | 首版明确拒绝，后续适配 |
| 硬编码 `content.json`、DLL、XNB | 不扫描、不修改 |
| 复杂事件、分支对话、未知控制语法 | 跳过并在报告中列出；该键使用默认语言 |
| 自动发现游戏位置、一键写入、协作平台 | 后续计划 |

当前保守支持 `{{…}}`、`@`、`%name`、`#$b#` / `#$e#`、`$0`—`$5`、`$h/$s/$l/$u/$n/$a` 等简单标记；要求标记内容、数量和顺序一致，以及换行数量一致。含额外 `$ # ^ [ ] / % { }` 等未知结构时按不支持处理，可能跳过含普通斜杠的文本。**不是完整的游戏脚本解析器**。

未译或不支持项不会写空字符串，而是省略目标键以使用 SMAPI 默认语言回退。已有中文中的额外键会归档而不写入新包。安装会替换整个 `zh.json`，务必备份。
