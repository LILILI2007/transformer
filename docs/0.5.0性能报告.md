# 0.5.0 本地性能与验收报告

测试环境：Windows、Python 3.9、HTTPX 0.28.1；自动测试不使用真实密钥。固定延迟是模拟值，以下耗时不能推算玩家的付费 API 耗时或价格。

| 项目 | 结果 |
|---|---:|
| 1,000 条，固定每请求 0.1 秒，串行 | 5.660 秒 / 50 请求 |
| 同一负载，4 路并发 | 1.798 秒 / 50 请求 |
| 吞吐倍数 | 3.15 倍（要求 ≥2.5） |
| 10,000 条，固定每请求 0.005 秒 | 5.884 秒 / 500 请求 |
| 并发峰值 | 4 |
| 万条缓存复跑 | 1.821 秒 / 0 新请求 |

复现：`python scripts/benchmark_engine.py`，输出 `artifacts/performance-0.5.0.json`。基准包含扫描、提取、SQLite 提交、安装与报告；使用 MockTransport，未走外网。压力测试产生 508 次进度事件；另有每秒心跳用于慢请求/准备阶段。

自动回归共 133 项，132 通过、1 跳过；跳过项需要 Windows 创建符号链接的权限。范围包括真实本地 HTTP 的 12 个 API 预设、异步连接池、限流退避、总超时、停止不再调度、8 次预算、部分返回仅重试缺失、旧缓存幂等迁移、玩家修改、升级后重译、备份恢复、CP 引用边界和结构重建。测试中的 Tk 多窗口销毁有一次主题事件提示，断言均通过。

本机 122 个 mod 的只读审计：71 个可提取文字，85,075 个片段；34 可直接翻译、37 部分支持、26 需进游戏采集、8 待确认、6 文件异常、11 无需翻译。完整逐个名单随包位于 reports。分母不能把未知 mod 当成无需翻译，因此没有宣称全库 90% 达标。

实际游戏探针使用独立 Mods 目录，未加载玩家存档。SMAPI 4.5.2 / 游戏 1.6.15：资源字段中文替换通过，DLL 绘制中文替换通过；asset/draw/GMCM 三种入口均采集到文字。GMCM 实际菜单显示与玩家真实 XNB 资源仍待验收。探针是受控样例，不能代替 122 个 mod 的实际游玩验收。

二十分钟为优化目标。真实速度受原文量、输出长度、限流、模型响应与需要采集的界面数量影响；软件根据当前吞吐估算，不到时强制截断。
