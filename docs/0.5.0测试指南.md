# ModLingo 0.5.0 本地测试指南

这是本地测试版，先交付 Windows 便携包、离线伴随插件、覆盖表和性能报告；尚未发布新的 GitHub Release。请完整解压目录，再运行 `ModLingo.exe`，无需安装 Python。

## 玩家操作

1. 退出游戏及 SMAPI。打开软件，自动识别或手动选择游戏目录，确认 Mods 清单。
2. 配置厂商、模型 ID 与密钥，点击验证。验证会发送短文本，可能计费；验证通过才能翻译。密钥只留在本次程序内存。
3. 默认全选；可以按分类决定先处理哪些 mod。并发默认 4，范围 1–6；服务限流时程序自动降低并发。点击“翻译并安装”。
4. 观察文本片段完成数、缓存命中、处理中请求、等待重试、最后响应和预计剩余时间。大型缓存迁移时阶段会显示“扫描/迁移缓存”，不代表正在调用 API。
5. 查看结果名单及条目覆盖数。部分完成表示仍有原文或未知语法保留，不能当作整个 mod 汉化成功。进入游戏检查实际界面。

需要 DLL/XNB 支持时：退出游戏 → 软件中点击“安装采集插件” → 用 SMAPI 启动，访问 GMCM 和相关 mod 的界面 → 退出游戏 → 回桌面软件重新扫描并翻译 → 再启动游戏检查。采集仅覆盖访问过且能确定所属 mod 的文字，不保证第一次启动就出现完整中文。

游戏内语言须设为简体中文。插件在实际资源被游戏及 CP 解析后，仅当 mod 版本、字段位置、原文与哈希匹配时替换；条件变化或玩家输入不进行猜测替换。不同条件产生不同原文时可能需要再次访问和翻译。

## 停止、恢复和备份

“停止并保存”取消本地等待并停止新请求，已校验返回的片段保存在 SQLite。已发往服务商的请求仍可能计费。重新开始只请求缺失结果；不在后台自动补发无法确认已返回的请求。停止时尚未安装的 mod 留待下次安装。

缓存、任务记录、名单和安装备份位于 `%LOCALAPPDATA%\ModLingo`。新缓存为 `translations.sqlite3`；旧 `batch-projects/*.json` 按需迁移一次，保留原文件。缓存按接口、模型、语言、mod、上下文、原文、术语和解析器版本隔离。来源不明旧候选只有通过原文、上下文与结构检查才复用。已有有效中文和玩家修改优先保留。

i18n 安装继续做快照检查、备份和原子替换；并发只用于网络，文件由单个写入器操作。CP 原文件、DLL、XNB、存档和损坏 JSON 不自动改写。结果页可恢复备份；文件后续被玩家改动时拒绝直接覆盖。

卸载采集插件只移除其 DLL/manifest；采集和译文保留。插件目录为 `Mods/ModLingo.Bridge`，不包含密钥、不联网、不调用翻译 API。

## 支持范围与分类

| 分类 | 含义 |
|---|---|
| 可直接翻译 | 当前有可提取文字；i18n 可写入中文，资源译文需伴随插件应用 |
| 部分支持 | 已提取部分文字，动态引用、未知命令或异常子文件等仍需处理 |
| 需进游戏采集 | 当前无法静态确认全部文字；先安装插件并访问相关界面 |
| 无需翻译 | 确认仅图像或非文本数据；不计作翻译成功 |
| 文件异常 | 无效 manifest、重复键、损坏 JSON 等；保留原文件并说明原因 |
| 待确认 | 尚不能确定有无可见文字，不能算作无需翻译 |

支持平铺/分文件 i18n、CP Include 和明确 JSON Load 的文本字段、对话、邮件、部分事件文本命令、任务标题/描述/目标、物品显示名称/描述。ID、路径、条件、附件和未知命令不作为普通文字翻译。图片烘焙文字不做 OCR。

DLL 优先处理 GMCM 标签/提示委托；绘制入口只处理可归属到已加载 mod 的已知字符串常量，动态拼接、聊天和玩家输入不在通用采集范围。XNB 只处理已归属资源加载后的文字字段，不解包或覆盖 XNB。未知资源类型及来源不明确的文字保持原样。

## API 与时间

保留 DeepSeek、千问/百炼、Kimi、OpenAI Chat/Responses、Claude Messages，以及 Gemini 兼容接口、硅基流动、OpenRouter、Ollama、LM Studio 预设。完整地址和模型填写方法见 [API 支持名单](API支持名单.md)。兼容的是指定协议和非流式文本响应，不代表所有厂商、所有模型都可用。

自动测试使用模拟响应和本地 HTTP，不使用真实密钥。实际耗时、价格和模型质量需要玩家验证后试译记录。二十分钟是优化目标，不会到时强制截断；预计时间根据已完成片段吞吐更新。费用金额尚未自动计算。

## 本次验收限制

全库 122 个 mod 的静态覆盖表随测试包交付。DLL 未访问界面、未知资源与异常文件尚未逐个游戏验收，**不宣称全库 90% 游戏内成功**。适配器探针与真实 mod 的验收分开记录。

隔离游戏探针已验证资源字段与 DLL 绘制文字的中文替换，以及 GMCM 文字采集；GMCM 菜单实际显示、真实 XNB 文本来源和全部条件剧情仍待玩家游戏验收。测试未加载玩家存档，未使用付费 API。
