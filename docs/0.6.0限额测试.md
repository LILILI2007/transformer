# 0.6.0 本地测试说明

双击 ModLingo/ModLingo.exe。先安装/更新伴随插件，用 SMAPI 打开需要汉化的 GMCM 页面、下拉选项，退出游戏后重新扫描、配置并验证 API，再翻译。插件只改显示译文，不改配置实际值、UniqueID、玩家输入或存档。

## 已修复

- GMCM 自动 GUID 字段采用稳定上下文，避免下次启动译文失配。
- 数字格式委托采用单数字模板，7 days、9 days 共用一条译文；多数字复杂格式暂不猜测替换。
- 游戏早期注册的常量文字延后采集；常见 mod 名称使用精确匹配的中文别名。陌生专名原样返回仍标为需要别名，不冒充完成。
- DeepSeek 短保护标记，冲突时退回随机标记；缺失、重复、错序和未知标记仍严格拒绝。
- 已知图像 Load 单列无需 OCR；含配置项的图像包仍需 GMCM 采集。
- 并发可选至32；财务预留暂时占满时等待核算，实际预算不足才停止。
