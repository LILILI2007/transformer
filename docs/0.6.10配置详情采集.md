# ModLingo 0.6.10 / Bridge 0.5.5：配置详情文字

针对玩家截图中的 No Pam Enabling、Standardized Seed Sprites 和 Integrated Minecarts，补充 GMCM 实际读取选项名称、说明、分组与页面标题时的文字采集和译文匹配。早期注册、未经过注册拦截的文字也可采集。下拉项没有格式器时采用原始值作为显示原文，替换的只是显示结果，Choices、配置键、读写委托和玩家输入保持原样。

新增四个按 UniqueID 和原始名称精确匹配的人工中文别名，覆盖截图三个 mod 及矿车 SMAPI 组件。已有玩家名称译文优先。其他详情文字仍需要采集、翻译、重启加载，不能仅安装新插件就认为全部完成。

修复空 i18n/default.json 导致独立插件字典无法安装的问题；不改写空原文件。已有 API 上下文译文按同 mod、相同原文及哈希复用，避免重新收费翻译。文字委托在 UI 调用时才执行，null 提示保持 null，缓存显示委托避免每次读取重复创建。

## 玩家验证步骤

1. 退出游戏。运行新的 ModLingo.exe，点击“安装采集插件”，确认 Bridge 0.5.5。旧 captures/translations 保留。
2. 启动游戏，分别进入三个 mod 的详情页；展开下拉列表、打开子页、悬停说明。只打开 mod 总列表不能采集未读取的详情文字。
3. 退出游戏，在桌面软件重新扫描，翻译新增采集文字。已有译文和缓存继续复用；用户手动发起的翻译仍可能计费。
4. 重新启动游戏，回到相同页面检查。矿车目的地应只改变显示，不能把 config.json 中的 jibb.Farm 等实际值改成中文。
