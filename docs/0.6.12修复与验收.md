# ModLingo 0.6.12 本地测试版

配套 Bridge 0.5.6。保留 0.6.11 包，升级不清空已有中文、缓存、采集或备份。

## 本次修复

- 待处理数量按文本记录统计；同一文本的多条诊断归并在 reasons 中，diagnostic_count 保留原诊断数量。原有 skipped 字段仍可读取。
- 缺失 UniqueID 的异常条目显示原始扫描原因，不再被“重复 UniqueID”覆盖。
- 已提取的 Content Patcher 引用资源保存逐文件摘要，安装前再次检查修改、删除及路径边界；冲突只影响相关 mod。
- 片段修复后仍原样返回时保存 unchanged 原因，不误记为结构异常。全局内容保护必须积累六个终结批次，并满足至少三个 mod、至少四批完全协议/结构失败。
- 服务配置校验错误直接停止，不作为内容错误反复请求。
- GMCM 实际框架测试新增自有测试选项的选择与保存流程，确认显示“巴士站”时实际值仍为 Bus；只修改隔离测试对象。

## 使用与边界

退出游戏后运行 ModLingo.exe，选择游戏目录，安装配套 Bridge，在程序中配置 API 后自行启动补译。验证和翻译会计费；开发没有调用收费翻译 API。默认复用缓存，只补缺失；显式重试待处理可能再次计费。

具体程序启动、离线回归、真实框架及逐 mod 结果见 reports。程序测试通过不等于全库基本汉化通过。未知文本和存档依赖剧情仍未验证，完整页面布局仍待检查；玩家已有语义错误译文不会被擅自覆盖。

旧版原生配置兼容、别名限定与失败隔离说明见 0.6.11 文档。裸数字 CP 属性键仅按已确认的 Newtonsoft 语法读取，不改写原始 JSON，也不取消重复键校验。
