# ModLingo 0.6.13 / Bridge 0.5.7

本版将自动采集插件整合进桌面程序，不再需要另外拼装 0.5.7 补丁。旧包保留。

## 本轮修复

矿车设置中，一个内部目的地标识重复出现在约 150 个排序下拉框。上一轮真实翻译报告中，矿车有 12079 条待处理，诊断为 unchanged 7089 条、scope_paused 4990 条；不能把它们都当成缺少游戏点击采集。

新版本仅针对 jibb.minecarts 的编号目的地下拉及对应说明，复用同一个 mod 自带的已有中文目的地名称。需要唯一名称对应；不同来源译名冲突时不选择其一。报告 display_label_reuse 列出来源文本键及原文/译文哈希。配置实际值、Choices 和字段 ID 保留原样。

缺少唯一可靠显示名称的目的地标识列为 alias_required，不自动请求翻译，仍计入待处理。显式重试也不能补出缺失的名称对应关系。已有译文与玩家主动回退优先；旧缓存键和数据库保留。

## 使用

退出游戏后启动新包的 ModLingo.exe，扫描当前游戏并使用已有缓存，只补缺失。程序在安装插件译文时会升级到配套 Bridge 0.5.7，也可在界面安装配套插件。不要删除旧的采集文件、translations 或缓存目录。

开发验证不调用收费 API；玩家主动启动在线补译仍可能计费。启动游戏会自动收集支持的静态文字，正常游玩继续采集动态文字。详情见 Bridge-0.5.7自动采集.md；该文档关于旧 0.6.12 内置插件的提示不适用于本新版。

## 保留的质量问题

种子贴图两条编号告警来自同一原文 `(1) Sensible Sleeves`，已有译文为 `(5) 合理袖袋风格`。建议将开头 `(5)` 改为 `(1)`；本版没有擅自覆盖已有中文。两条告警分别是原生 config.Seed Packet Variant.values.(1) Sensible Sleeves 和 GMCM 显示记录。其他拉丁字母告警仍需区分专名与漏译。

## 验证与验收边界

完整回归 292 项：291 通过、1 跳过，零失败零错误。测试入口改为独立脚本以支持 Windows 子进程；GUI 测试仍有 ThemeChanged 销毁提示，未声称所有 GUI 生命周期问题均已解决。

全库覆盖、实际框架探针和打包证据见 reports。本版主要修复名称复用及无意义的重复请求；不能把已有中文复用当作人工语义审校，也不能用全局覆盖率代替每个常用菜单的验证。存档依赖剧情和完整页面布局仍未完成验收。
