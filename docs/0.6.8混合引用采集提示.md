# 0.6.8 混合引用的待采集提示

含i18n引用的事件/资源必须先由Content Patcher解析，桌面不能把带引用的源代码当作游戏最终原文改写。纯i18n引用继续走原i18n路径；同一字段还有硬编码英文时，新增pending_captures清单，记录来源文件、asset、path、context、原因和操作步骤，不重复向API发送引用。

报告区分observed_path：只有匹配mod版本、有效原文哈希、相同资源/字段位置且已解析的asset采集才标记已观察。错误版本、损坏哈希、其他路径、仍含i18n引用的内容都不算。一个位置已观察只代表该次加载，不证明其他条件版本覆盖，所以状态仍保守标为部分支持/部分完成，游戏内生效仍待验收。

操作步骤：启用ModLingo.Bridge并正常进入游戏，访问报告asset对应的地图或相关界面，使游戏加载资源；退出游戏后回到桌面工具重新扫描并翻译。只需处理新增采集，保留已有缓存。条件剧情可能需要其他游戏状态才加载，不承诺访问一次就全部采集；软件不自动操作存档。结果报告JSON及覆盖表CSV/JSON中的pending_captures可逐项查看来源和位置，主界面状态/原因显示待采集数量与提示。

安装报告不再因为当前提取记录全部处理就忽略这类缺口。没有可静态翻译记录时返回“需进游戏采集”；已有i18n全部安装但仍有混合字段待采集/条件验收时返回“部分完成”。不把纯引用或脚本内部ID误当额外翻译需求。旧后台准备文件缺少新字段时仍可读取。
