# 0.6.9 世界地图文字与 Bridge 0.5.4

支持Data/WorldMap的区域底部滚动文字ScrollText和悬停提示Tooltips/Text。列表按唯一字面Id定位，支持静态TargetField和Fields，模型字段名规范大小写而保留ID大小写；不按当前数组顺序猜位置。只处理确认的人类可见字段，地图条件、坐标、图片、世界定位、内部Id及邻接Id保持原样。

桌面与Bridge采用一致路径：Region/MapAreas/AreaId/ScrollText，以及Region/MapAreas/AreaId/Tooltips/TipId/Text。完整原文/哈希匹配才替换，同词不同区域不会串译。数组顺序改变后上下文仍稳定。重复/缺失/动态Id、#序号选择器及超出格式的路径保留待处理；其他资源的通用列表ID未在本轮适配。纯i18n引用继续走原路径，混合引用或其他动态文本需游戏解析采集，不把未解析代码当作最终原文请求。

固定122项快照从54093→54132记录、90936→90967片段；新增3个mod的地图路径：Nora The Herpetologist 1记录/1片段，Remapping 25记录/17片段，Stardew Valley Expanded 13记录/13片段。记录可能为空或已有中文，片段不等于HTTP请求或已完成译文。总分类仍34直接、57部分支持、16需采集、8待确认、5无需、2文件异常，因为这些mod仍有其他覆盖缺口。所有玩家mod逐项游戏验证仍false。

263项回归：262通过、1符号链接权限跳过，34.216秒。新增11项覆盖唯一Id、重排、字段名、TargetField、Fields、重复/缺失/动态Id、非可见字段、混合引用、动态值和相似未知资源名。Bridge及探针编译零警告、零错误。隔离真实标题资源探针加载CP实际编辑后的世界地图：滚动文字、嵌套提示变中文；同词不同Id保持原文，过时原文哈希未覆盖当前文本，坐标/条件/邻接Id与顺序不变；有效路径被归属采集，重复Id的独立内存fixture跳过。没有打开玩家存档或地图窗口，屏幕排版及玩家具体地图效果仍待验收。

使用：退出游戏，运行新包内ModLingo/ModLingo.exe，点击“安装采集插件”把Bridge升级至0.5.4（保留captures/translations），再重新扫描、验证自己的API并翻译。启用SMAPI进入相关地图加载资源后，如仍有残留，退出游戏再扫描新增采集。不要在游戏运行时安装。自动测试没有替玩家改写Mods；旧版本包保留。
