# Beta验收范围

自动化通过不替代真实模型质量、第二台电脑或完整存档剧情验收。

## 自动化流程

发布前核对源码版本、Bridge版本、校验值、回归和打包启动；以临时样例和模拟模型执行：

1. 空缓存、原作者已有中文，安装i18n、资源字典及Bridge。
2. 验证名称依赖同轮回填、配置和来源文件不被改写。
3. 复跑复用缓存，不新增模拟请求。
4. 修改原文，只补译变化内容，保留未变译文。
5. 校验备份恢复，拒绝覆盖玩家后续编辑。
6. 在解压目录以隔离配置、去除开发工具的PATH运行程序。

模拟响应费用为零，临时文件不是玩家mod。报告必须明确 `external_windows_verified=false`、`game_display_verified=false`。

## 人工待办

| 项目 | 状态 | 完成方式 |
|---|---|---|
| 第二台无开发环境Windows | 待办，用户目前无第二台电脑 | 志愿者独立下载和启动 |
| 真实付费API和真实mod | 本版发布流程不重新付费调用 | 取得预算和有效凭据后另测 |
| 菜单、地图及存档剧情 | 未全量验收 | 自己的备份环境逐项观察 |
| 升级、恢复、管理器部署 | 自动化部分覆盖 | 志愿者记录部署位置和结果 |

用户已选择自动化验收通过后继续费用控制和开发者上手改进，保留人工待办。公开Beta文案不得把这些待办标成完成。
