# Bridge 0.5.7 自动采集补丁

配合 ModLingo 0.6.12 使用。此包只升级采集插件，不代表全库汉化验收完成。

## 玩家操作

1. 退出游戏和 SMAPI。
2. 将本包 `ModLingo.Bridge` 文件夹中的四个文件复制到游戏 `Mods/ModLingo.Bridge` 中，覆盖同名文件。不要删除原文件夹；其中的 captures.json、translations 和其他数据需要保留。
3. 启动游戏即可自动收集支持的静态设置文字。正常游玩时继续自动补采动态文字，无需为了静态文字逐个打开设置选项。
4. 退出游戏后，用已有 ModLingo 程序扫描并只补缺失。实际翻译仍由玩家在程序中主动启动，不会在游戏中自动调用 API。

注意：旧版 0.6.12 程序自带 Bridge 0.5.6。不要在旧程序中再次点击安装旧插件，否则需要重新复制此补丁。现有缓存和译文继续使用。

## 本次增加的无需点击采集

- 直接返回已有实例字符串字段的设置名称、说明、分组文字和页标题；仅识别严格限定的 IL 形态，不运行委托。
- 无自定义显示函数的下拉选项，按实际原始显示文字收集，保留选项值。
- 继续支持原有常量文字和 mod 名称的注册时采集。

自定义显示函数、复杂计算、属性访问和存档相关委托继续等实际显示时采集；不自动打开所有页面、不修改配置、不读取玩家存档。此版不是所有 GMCM 文本的一次性全量抓取。桌面程序本来可直接提取的 i18n 和结构化资源仍无需玩家点击。

## 验证

Bridge 与探针构建均为零错误、零警告。真实 SMAPI/GMCM 隔离标题探针通过：菜单打开前已捕获字段标签及两个下拉选项；存档依赖函数和自定义格式函数未被提前调用；原有延迟/null/页面/重复包装/原始选项值、资源及显示命中回归通过。测试不打开存档、不调用收费 API，不覆盖玩家 Mods。

该测试是隔离测试对象的真实框架验证，不等同于全部实际 mod、所有页面布局或动态剧情已验证。测试证据见包内 startup-probe.json。
