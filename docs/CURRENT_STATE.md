## 0.6.14 历史矿车资源适配

- Python 与 Bridge 识别 `Data/Minecarts` 的目的地显示名称和文档规定的提示文字；目的地列表按唯一静态 Id 定位。
- 独立名称解析器连接目的地标识、原作者 i18n、已有合格缓存与游戏返回的本地化文字。跨模组名称有明确定义来源；同名冲突或未知定义不择一猜测。
- `LocalizedText` 引用由中文游戏读取内置语言资源；采集记录保留原始引用、原文及解析结果哈希和语言。未匹配当前定义的观测不复用。
- 动态/玩家自定义名称不派发给模型，不改配置值、地图、价格、目的地 Id 或自定义元数据。安装前复核跨模组名称来源。
- 未实现同轮翻译后的依赖重算；缺少名称提供方和运行时证据仍明确待处理。没有为填满比例硬译内部标识，也不宣称覆盖率已达到95%。
- 新增边界测试、跨模组副本测试及真实框架标题探针；具体证据与本版说明一起交付。历史0.6.13覆盖率数字不作为本版验收结果。
