# ModLingo 0.5.1 本地修复版

修复内部合并标记与未知标记校验冲突导致的有效译文拒绝。合并/批次按输出开销收缩，截断后降低后续批次大小；拒绝与工具调用不反复重试，近期失败占比过高时暂停。保留每批最多 8 次 HTTP 预算、并发和缓存恢复。

修正预计时间，分开成功、失败及缓存计数。补足事件内分支参数和数字头像保护。新逐请求诊断记录状态、耗时、预算及校验原因，不保存密钥或文本正文。

142 项回归中 141 通过、1 项权限跳过；真实准备数据的 51,189 条记录/85,075 片段通过离线结构回归。模拟结果不代表译文质量或真实 API 时延。详见 0.5.1 修复说明。

保留旧缓存和备份；插件继续使用 0.5.0。本次先交付本地修复包，未发布新的 GitHub Release。
