# ModLingo 0.1.0 预览版

Windows 中文桌面工具，帮助玩家翻译星露谷 mod 的标准平铺 i18n 文件。

## 使用

下载 `ModLingo-Windows-x64.zip`，解压后运行 `ModLingo/ModLingo.exe`。保留整个文件夹，不要只复制 EXE。程序未签名。

可先打开原创示例进行编辑、保存和导出。自动翻译需要自行配置兼容 Chat Completions 的 API 地址、模型名称及密钥，费用由服务账号承担。密钥只在进程内存中使用。

## 功能

- JSONC/BOM 导入，保留已有中文，人工编辑与术语表。
- 模型批量翻译、占位符保护、响应检查、限次重试与停止后续请求。
- 按 UniqueID 和源文比较更新，复用未变译文，变更候选需确认。
- 本地自动保存、项目副本、仅翻译 ZIP 及安装恢复说明。
- 主动清空并保存的译文保留默认语言回退选择，原文变化后重新复核。

## 验证与边界

本地 36 项自动测试、源码 GUI 启动检查及便携程序启动检查通过。测试含本机 HTTP 模拟接口与导入、翻译、修改、保存、更新、确认、导出的完整流程。

此版本为预览版。尚未完成商业云 API、真实 mod 的游戏内显示和无 Python 干净机器验证。分文件 i18n、硬编码 content.json、DLL/XNB 和复杂对话脚本暂不支持，跳过项会列入报告。原 mod 文件只读，安装翻译前应自行备份 zh.json。

`SHA256SUMS.txt` 提供下载完整性校验；这不等于程序签名。源码使用 MIT 许可证，第三方组件许可随便携包提供。
