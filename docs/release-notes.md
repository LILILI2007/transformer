# ModLingo 0.2.0 预览版

面向玩家的一次处理多个 mod 的流程：运行 → 自动识别游戏与 Mods → 配置 API → 默认全选或勾选 mod → 翻译并安装 → 成功/失败名单 → 用 SMAPI 启动中文游戏。

## 新功能

- 自动检查 Windows 注册表、Steam 库和游戏清单、常见 Steam/GOG/Xbox 位置，记住游戏目录；多份安装需选择，识别不到可手动指定。
- 扫描分组文件夹下的 mod，默认全选，逐个显示处理状态及失败原因。
- 批量翻译并直接安装 i18n/zh.json，未变译文与成功批次复用；无需手动复制 ZIP。
- 已有中文自动备份，可从结果记录恢复；保留已有额外键和复杂项。
- 成功、失败和部分完成名单，含每条跳过原因；不支持项不计为全部成功。
- 目录与文件快照复查、同目录进程锁、游戏运行检测；后续玩家修改不会被恢复操作覆盖。
- 停止后续请求、失败续跑、服务配置错误停止后续付费调用。
- 保留“单 mod 编辑”入口。后续支持玩家指定翻译语言。

## 使用

下载 ModLingo-Windows-x64.zip，解压后运行 ModLingo/ModLingo.exe。保留整个文件夹，无需 Python。程序未签名。准备自己的兼容 API；调用可能计费。先退出游戏和 SMAPI，翻译完成后通过 SMAPI 启动，并把游戏语言设为中文。

## 兼容与验证

当前只支持标准平铺 i18n 文本。分文件 i18n、硬编码 content.json、DLL/XNB、复杂脚本、目录链接和重复 UniqueID 会说明原因；部分可译的 mod 会安装可用部分，列入部分完成名单。自定义 --mods-path 暂不自动推断。

本地共 61 项测试，60 项通过，1 项因 Windows 链接权限跳过；包含目录探测、批量安装、失败续跑、更新、备份恢复、修改保护和 GUI 检查。云端验证结果见仓库 Actions。尚未完成真实云 API、真实 mod 游戏内显示与无 Python 干净机器验证。不能保证所有 mod 均为中文。
