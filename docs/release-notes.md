# ModLingo 0.3.0 预览版 · 农场风格界面

第三次 GitHub 版本发布，重做界面并保留自动目录识别、批量翻译、中文安装与备份恢复流程。

## 新界面

- 原创像素景观：蓝天、山丘、木牌、树木、农舍、小鸡与幼苗，搭配木框及暖色纸张面板。
- 批量界面、API 设置和单 mod 编辑器统一配色与控件风格，无新增运行依赖。
- 发现/已勾选/成功/需要关注四项统计，结果用中文与颜色同时区分。
- 搜索名称、UniqueID、目录或原因，筛选已勾选、成功和需要关注；筛选不取消隐藏项目的勾选。
- 选中行查看完整原因，空清单提示；小窗口自动缩短横幅、收起统计，主操作保持可见。

## 下载与使用

下载 ModLingo-Windows-x64.zip，完整解压后运行 ModLingo/ModLingo.exe。自动识别游戏目录，点“配置 API”，勾选 mod 后点“开始翻译并安装”。结束后点“查看结果名单”。程序未签名，无需安装 Python。

已有中文改写前仍自动备份，原有项目、备份与结果记录可继续使用。当前仍为英语→简中、标准平铺 i18n，复杂脚本及硬编码内容可能无法翻译。先退出游戏和 SMAPI，安装完成后以中文启动游戏。

## 验证与素材

本地 65 项测试中 64 项通过，1 项链接测试因 Windows 权限跳过；源码及便携启动检查在发行时核验，云端结果见 Actions。新增验证覆盖筛选保留勾选、隐藏行结果更新、重新扫描和小窗口主操作可见性。真实云 API、游戏内效果与无 Python 玩家机器仍待验证。
