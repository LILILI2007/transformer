# 0.4.0 玩家使用指南

## 下载和运行

下载 GitHub v0.4.0 发行页中的 ModLingo-Windows-x64.zip，解压整个文件夹，打开 ModLingo.exe。程序无需安装 Python，未签名。首次启动自动查找游戏与 Mods；之后记住上次目录并重新扫描。

自动识别检查 Steam 注册表、Steam libraryfolders.vdf 和游戏清单，以及常见 Steam/GOG/Xbox 位置，不遍历整个硬盘。存在多份游戏时从下拉框选定一份；未找到时手动选择包含游戏程序和 Mods 的目录。尚未安装 SMAPI 或 mod 时，应先完成安装。

## 配置并翻译

点“配置 API”，先选厂商预设，再填写服务商控制台的模型 ID 和密钥。支持 DeepSeek、千问、Kimi、OpenAI、Claude，并扩展 Gemini 兼容接口、硅基流动、OpenRouter、Ollama 和 LM Studio。详细地址、协议和限制见 [API支持名单](API支持名单.md)。远程地址必须为 HTTPS；本机模型可用 loopback HTTP。保存并测试会发一句测试文本，可能计费。密钥不保存到磁盘，重新运行需重填，也可用 MODLINGO_API_KEY 环境变量。

mod 默认全选，点击最左侧选择列或按空格切换；也可以全选或全不选。无法处理的 mod 同样显示并默认选中，以便最终名单完整说明原因。

退出游戏和 SMAPI，点击“开始翻译并安装”。确认后开始发送待译文本、翻译键及相关术语，费用由你的 API 账号承担。成功翻译直接写入各 mod 的 i18n/zh.json，写入前自动备份原中文。不会修改 default.json、manifest.json 或游戏语言设置。

停止按钮停止后续请求，不撤销已发出的调用；当前响应返回后保存进度，但尚未安装的 mod 不再安装。运行中关闭窗口会请求停止，等待任务结束后再关闭，避免中断安装。

### API 配置注意事项

千问北京/新加坡密钥与地址须对应，预设默认关闭思考，须选择支持该模式的非流式文本模型。Claude 使用原生 Messages，多工作区密钥填写工作区 ID。OpenAI 按模型支持情况选择 Responses 或 Chat Completions，不能把两种完整地址混用。其他协议和特殊鉴权未实现。

输出上限默认 8192 tokens，须符合模型限制；超时默认 60 秒，较慢模型可先调整为 120 秒。切换厂商会清空密钥和模型，避免误发凭据。简单连接测试不代表全部 mod 可译，先少量试译。当前各厂商通过本地协议测试，真实服务均待用户凭据验收。

## 搜索与筛选

顶部统计显示发现的 mod、已勾选、已成功和需要关注的数量。输入名称、UniqueID、目录或错误原因搜索，右侧可切换全部、已勾选、成功、需要关注。筛选不会取消隐藏项目的勾选；全选/全不选作用于整个清单。开始前检查“已勾选”数量。

成功行显示绿色，失败行显示红色，部分完成或无法处理显示暖黄色，均保留中文状态。选中一行，清单下方显示完整原因。小窗口会收起统计卡片并缩短景观横幅，让主要操作保持可见。

## 查看结果

每个 mod 实时显示状态与原因。完成后点击“查看结果名单”。本机 reports 下的 TXT 便于阅读，JSON 含每条跳过原因、安装数量和恢复凭据。

成功表示源文条目全部有通过当前检查的译文；不代表人工精修或游戏内验证。部分完成表示已安装可用部分，复杂语法等仍未译，归入失败或部分完成名单。彻底失败不会替换该 mod 的中文文件；其他 mod 继续。

400/401/403/404/429 时会停止剩余付费请求，避免错误配置连续消费。已完成的 mod 不回滚。修正配置或文件后重新扫描再开始，成功批次和未变译文会复用。

请通过 SMAPI 启动游戏，并把游戏语言设为中文。游戏仍显示英文时，核对名单中的跳过原因、是否选择了实际运行的游戏目录、mod 是否真的使用 i18n，以及是否重启游戏。自定义 --mods-path 或管理器隔离环境目前不能自动识别。

## 恢复中文

点击“恢复中文备份”，选择本次 reports 中的 JSON。已有中文恢复到原字节内容；此前没有中文则移除本次新增的 zh.json。默认只恢复这次实际改写过的文件。若玩家在安装后又修改中文，恢复会跳过，避免丢失后续编辑。

不要删除 %LOCALAPPDATA%/ModLingo/backups 后再尝试恢复。记录中的路径和 mod 身份、备份内容及当前文件哈希会检查；目标变化时停止恢复。

## 高级编辑与边界

“单 mod 编辑”保留示例体验、人工编辑、术语表、更新比对和 ZIP 导出。无需 API 也能编辑。它与批量工作缓存独立；批量安装以实际 mod 文件和批量进度为准。

当前仅平铺 i18n/default.json / zh.json，支持 JSONC、BOM、尾逗号，拒绝重复键与非字符串值。不提取硬编码 content.json、DLL 或 XNB；复杂语法会跳过并报告，已有对应中文仍保留。新语言选择属于后续开发方向。
