# 使用指南

## 启动和不花钱体验

便携版：解压发布包，双击 `ModLingo.exe`。完整保留程序目录。

源码版：安装包含 Tkinter 的 Python 3.9+，双击 `Start.cmd`。如系统把 `python` 指向商店占位程序，改用终端在项目目录运行 `py -3 -m modlingo`，或使用正确的 Python 完整路径。

点击“打开示例”，选“Starfruit Jam”，在右侧填写“杨桃果酱”，点击“保存 / 确认此条”。这一步无需 API。导出 ZIP 后可以检查里面的中文 JSON、安装说明和报告。**演示素材只是测试文本，不能作为真实 mod 加载。**

项目进度自动保存在 `%LOCALAPPDATA%\ModLingo\projects\`，每个 mod 按 UniqueID 分开保存。下次导入同一 mod 会恢复进度并比对源文。需要转移电脑时用“保存副本”，在新电脑点“打开项目”。API 密钥不随项目迁移。

## 导入真实 mod

选择直接包含 `manifest.json` 的单个文件夹，例如 `Stardew Valley/Mods/SomeMod/`，不要选整个 `Mods` 文件夹。压缩包应先自行解压。

支持 `i18n/default.json`，可选已有 `i18n/zh.json`。允许 JavaScript 注释、尾逗号及 UTF-8 BOM。首版不接受分文件语言目录或嵌套对象/数组作为翻译值。默认把 default 文件当成英语，请自行核对。

已有中文会保留，但第一次导入时没有旧原文，程序无法知道现有译文是否过期。已有中文里的额外键留在项目归档中，不进入新导出文件。

## 配置大模型

点击“API 设置”，填写：

- 服务地址：服务商的接口基础地址，比如 `https://api.deepseek.com`；也可以填写完整的 `/chat/completions` 地址。
- 模型名称：从服务商控制台或文档复制，不能用网页聊天的显示名称猜测。
- API 密钥：从对应 API 控制台取得。网页聊天订阅和 API 计费不一定相同。

本工具实现 Chat Completions 格式的非流式文本请求，不保证支持所有标称“兼容”的服务。其他协议、工具调用或特殊参数要求可能需要新增适配器。当前没有接入供应商账号或代付系统。

“应用并测试连接”会发送一句测试文本，可能计费。正式翻译前会提示服务、模型、条目数和原文字符数；字符数不是 token 数或费用估算。发送内容包括待译文本、翻译键和相关术语，不包括整个 mod 文件或游戏存档。

远程地址必须为 HTTPS；本机部署可用 `http://127.0.0.1:端口/v1`，并填写本机模型名；本机服务可以不填密钥。程序不会跟随 API 重定向，请填写最终地址。远程数据处理政策以服务商说明为准。

密钥只保存在本次程序内存，可选通过 `MODLINGO_API_KEY` 环境变量传入。不要把密钥写进脚本、项目文件或截图。

## 翻译、修改和术语

点击“术语表”，每行写 `英文=中文`，例如 `Starfruit=杨桃`。术语随项目保存，相关项会被发送给模型；缺失预期译名时进入复核。已有人工译文不会因为改了术语表自动变化。

点击“翻译待处理文本”，程序仅提交待译支持项。未变且已有译文的项不会重复提交；变更项生成候选后也不会反复调用，需人工确认。暂不支持项不调用 API。

“停止后续请求”不会撤销当前已发送请求；它会等待当前批次返回或超时并保存结果，再停止。每次超时 60 秒、最多尝试三次，网络不好时可能等待约三分钟。失败重试也可能被服务端计费。

右侧编辑后点击“保存 / 确认此条”。切换条目时会保存发生变化的编辑；未修改的变更候选仍需要明确点击确认。检查失败的草稿可以保存，但不能进入有效导出。清空并保存代表该键导出时省略，使用默认语言；状态会显示“原文回退”，之后批量翻译不会重发此项；原文变化后会重新进入复核。需要重新翻译时可手动填写译文，或等待源文更新。

## 状态解释

| 状态 | 意义与操作 |
|---|---|
| 待翻译 | 还没有译文，可调用 API 或手动填写 |
| 可导出 | 现有中文或 AI 候选通过当前结构检查；不等于人工精修 |
| 人工已确认 | 已手动保存且通过结构检查 |
| 更新待确认 | 原文变化，需要对照旧原文/旧译文处理 |
| 译文待确认 | 原样返回或术语规则提示需要复核 |
| 检查失败 | 修复结构、调整 API 后重试，或清空保存来回退 |
| 原文回退 | 已主动清空并保存，导出省略该键，不再自动重译 |
| 暂不支持 | 复杂/未知语法或超长项，跳过并写入导出报告 |

首版语法检查保守，保留标记顺序，可能拒绝有效的自然语序重排或包含斜杠的普通文本。请不要为了绕过检查删除控制符。完整语法支持属于后续工作。

## 更新 mod

先保留项目，点击“载入更新”，选相同 UniqueID 的新版 mod 文件夹。项目会保留未变译文，对变更项留下旧原文、旧译文；新增项待译，删除项归档。重新导入附带的 zh.json 不会覆盖项目中已维护的译文。

可以用 `examples/DemoMod-v2` 体验更新。它改变一句问候、增加一项、删除两项复杂语法。素材文件夹名变化不影响身份匹配。版本号仅展示，选错旧版本仍会按其源文比较，请自行确认版本。

## 导出、安装与恢复

导出前处理所有支持项中的结构失败与待确认状态。未译项可以保留为空，但应先清除已有错误/待确认状态。暂不支持项会跳过。包里包含：

```text
原mod文件夹名/i18n/zh.json
安装说明.txt
export-report.json
```

关闭游戏，依据 UniqueID 找到原 mod；其实际文件夹名可以与 ZIP 中不同。先备份现有 `i18n/zh.json`，再把包内中文文件复制到原 mod 的 i18n 目录。该文件会整体替换，不会在安装时与旧文件逐键合并。不要覆盖 `default.json`，不要把翻译包作为独立 mod。

在游戏中选择中文并通过 SMAPI 启动，检查界面、物品和对应对话。可尝试 SMAPI 的 `reload_i18n`，但有些 mod 会缓存文本，重启更可靠。检查通过不等于所有剧情都检查过，需记录实际覆盖场景。

恢复时复制回原备份；此前没有中文文件就删除新增的 zh.json。工作台不会自动修改或备份游戏目录中的文件。

## 常见问题

- 没有 default.json：该 mod 没有采用首版支持的标准入口。content.json 中有英文也不代表能直接翻译。
- 检测到分文件目录：布局是 SMAPI 支持的形式，但原型尚未适配；不是该 mod 错误。
- 401：核对密钥、服务商和有效期；404：核对基础地址与模型名；429：检查余额和限流。
- 返回格式不兼容：模型可能没有返回所要求的 JSON，或 API 协议不同。可重试、换模型或提交脱敏样例。
- 一批失败后停止：避免错误配置把剩余所有批次都发出；成功批次已保存，修正后继续。
- 占位符检查失败：保留原文的 `{{…}}`、简单对话标记、替换符和换行。无法确认时清空保存，以回退原文。
- 游戏还是英文：核对游戏中文设置、原 mod 身份、复制路径、报告中的跳过项；确认 mod 实际使用 i18n；再重启。
- 中文乱码：导出为 UTF-8；不要用其他编码的编辑器重新保存。若仍存在，请在实机环境中排查字体或 mod 自身逻辑。
