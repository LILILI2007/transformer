# 兼容性与证据

“适配已实现”“自动化验证”和“真实玩家机器验收”分别记录；未列出的组合不自动获得兼容承诺。

| 项目 | 已有证据 | 边界 |
|---|---|---|
| Python3.9/3.11/3.13 | Windows2022、Ubuntu22.04回归 | Linux后端测试不代表Linux桌面发行包 |
| Windows x64便携包 | 本机、云端构建及启动 | 新电脑完整流程待人工验证 |
| 游戏1.6.15 / SMAPI4.5.2 | 隔离标题探针 | 不加载玩家存档，不代表全部剧情 |
| CP2.9.1 / GMCM1.16.0 | 支持资源和菜单探针 | 自定义、动态条件和未访问界面待采集 |
| i18n平铺、分文件 | 提取、安装、缓存、恢复 | 变化原文和结构异常需复核 |
| WorldMap、Minecarts | 白名单、稳定Id、来源映射与配置保持 | 不改Id、坐标、价格、条件和自定义值 |
| DLL/XNB | 已识别界面、绘制和游戏资源采集 | 不通用反编译，不保证任意字符串 |
| Vortex、--mods-path | 暂不自动推断隔离目录 | 处理选定游戏下的实际Mods，避免并行部署 |

API见[支持名单](API支持名单.md)。协议模拟与真实服务调用属于不同证据；其他模型、地域和网关不继承验证结论。

隔离副本规则合格记录约87.96%，不是人工翻译准确率、游戏显示覆盖率或任意用户安装的保证。
