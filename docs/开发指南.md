# 开发指南

玩家运行便携EXE，无需构建环境。源码最低Python3.9，GUI需要Tk。本机Anaconda记录见[环境迁移](Anaconda环境迁移.md)。

在自己的Python环境中安装和运行：

```powershell
python -m pip install -e . -r requirements-build.txt
python -m modlingo
python -m unittest discover -s tests -v
```

Windows构建显式选择当前解释器，避免依赖固定盘符：

```powershell
.\scripts\build_windows.ps1 -PythonPath (Get-Command python).Source
```

Bridge需.NET6 SDK和你自己安装的游戏、SMAPI程序集，不分发游戏文件：

```powershell
.\scripts\build_bridge.ps1 -GamePath '你的星露谷游戏目录'
```

规则源为 `modlingo/resource_rules.json`，Bridge构建时嵌入同一文件。修改规则后同步构建插件并执行契约测试。[贡献指南](../CONTRIBUTING.md)说明提交和脱敏边界。

## 从空环境开始

推荐任选一种，不需要在固定盘符安装：

```powershell
# Anaconda / Miniforge
conda env create -f environment.yml
conda activate modlingo
python -m modlingo --smoke

# 或标准Python，安装程序需包含Tk
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e . -r requirements-build.txt
python -m modlingo --smoke
```

`Start.cmd`和测试/构建脚本共享解释器查找：显式`-PythonPath`、`MODLINGO_PYTHON`、`MODLINGO_CONDA_ROOT`优先；否则查项目`.venv`、Conda报告的modlingo环境、当前环境、`.venv-build`及PATH中的Python。配置的路径不存在时直接报错，不静默切到别的环境。只调整子进程环境，不改系统PATH。

```powershell
$env:MODLINGO_PYTHON = (Get-Command python).Source
.\Start.cmd --smoke
.\scripts\test_windows.ps1
.\scripts\build_windows.ps1
.\scripts\verify_portable.ps1
```

Bridge默认通过注册表/Steam库查找唯一SMAPI游戏目录。多安装或自定义位置请用`-GamePath`或`MODLINGO_GAME_PATH`；SDK可用`-DotNetPath`或`MODLINGO_DOTNET`，否则使用PATH。需要.NET6 **SDK**，仅有运行时不够。跨语言契约测试同样支持`MODLINGO_DOTNET`。

## 修改后验证与发布

运行回归、GUI启动及打包验收；改共享规则需重建Bridge并通过Python/C#契约测试。CI在Windows2022与Ubuntu22.04的Python3.9/3.11/3.13检查，Linux不是玩家桌面发行目标。

发布流程先通过完整六组回归，再打包、执行隔离配置验收、校验源码与Bridge对应关系，生成校验文件后发布Beta。版本同时维护`pyproject.toml`和`modlingo/__init__.py`；发布标签保持不可改写，已发布问题用新版本修复。

自动化只用自有样例及模拟服务，不需要密钥、不收费。`scripts/run_limited_test.py`等是历史专项实测脚本，不是开发入口，仍受已过期的独立测试授权约束，不应直接用于新测试。`docs/Anaconda环境迁移.md`只记录维护者电脑的历史路径。
