# 开发指南

玩家运行便携EXE，无需构建环境。源码最低Python3.9，GUI需要Tk。本机Anaconda记录见[环境迁移](Anaconda环境迁移.md)。

在自己的Python环境中安装和运行：

```powershell
python -m pip install -e . -r requirements-build.txt
python -m modlingo
python -m unittest discover -s tests -v
```

Windows构建显式选择当前解释器，避免依赖固定盘符：

```powershell
.\scripts\build_windows.ps1 -PythonPath (Get-Command python).Source
```

Bridge需.NET6 SDK和你自己安装的游戏、SMAPI程序集，不分发游戏文件：

```powershell
.\scripts\build_bridge.ps1 -GamePath '你的星露谷游戏目录'
```

规则源为 `modlingo/resource_rules.json`，Bridge构建时嵌入同一文件。修改规则后同步构建插件并执行契约测试。[贡献指南](../CONTRIBUTING.md)说明提交和脱敏边界。

环境自动发现和开发流程进一步整理安排在自动化验收通过后。
