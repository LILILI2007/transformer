# 玩家指南

0.6.16起，API设置可填写本轮请求上限、token预算及服务商单价。默认500次/200万token；缓存复用不消耗请求额度。限额包括重试，达到后保留合格译文并暂停，剩余内容可在检查报告后继续。输入预留和金额是估算，服务商控制台额度才是账号费用约束。重新开始、编辑器和连接验证分别计一轮。

反馈时先点击“导出脱敏摘要”，它只导出版本、计数及用量，不含路径、原文或密钥；不要直接上传完整结果JSON、备份、存档和设置截图。

适用于0.6.15 / Bridge0.5.9 Beta。

## 下载与首次使用

到[本版发布页](https://github.com/LILILI2007/transformer/releases/tag/v0.6.15)，选 `ModLingo-Windows-x64.zip`，完整解压，运行 `ModLingo/ModLingo.exe`。不要在压缩包内运行，也不要只复制EXE。无需Python或Anaconda。

1. 先保留自己可用的mod备份，退出游戏、SMAPI和正在部署文件的模组管理器。
2. 确认识别出的游戏；多份安装选定一份，识别不到时选择包含游戏程序的目录。
3. 配置服务商、控制台模型ID和API密钥。网页会员不等于API额度。
4. 点“验证API”，阅读费用提示后确认，通过后才能翻译。
5. 首次只勾选1—2个mod，阅读请求计划后开始。
6. 查看成功、部分完成、待采集或暂停原因；通过SMAPI以中文启动游戏检查。

## 采集动态内容

点击“安装采集插件”，访问对应菜单、地图或剧情，再退出游戏、扫描和补译。动态内容需实际触发；一个条件版本不代表全部版本。

Bridge在本机工作，不保存密钥、不调用模型；桌面程序在你确认后才请求服务商。

## 恢复与升级

点“从结果记录恢复中文备份”，选择对应结果JSON。仅恢复该次记录内的文件；后续修改会跳过，避免覆盖新编辑。

把新程序解压到新目录，保留 `%LOCALAPPDATA%/ModLingo/` 中的缓存、报告与备份。退出游戏后更新Bridge并重新扫描。未变原文可复用合格译文，变化内容需要复核。

## 来源提示与反馈

当前程序未签名。确认下载来自本仓库，并按发布页SHA256核对；无法确认时不要运行。不要关闭Windows或杀毒软件的整体防护。

反馈请附版本、提示和最小复现；不要公开密钥、完整mod、存档或含私人文本的原始报告。更多问题见[常见问题](常见问题.md)。
