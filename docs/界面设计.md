# 0.3.0 界面设计与美术来源

## 视觉方向

按用户要求查阅星露谷物语 [官方主页](https://www.stardewvalley.net/) 与 [官方媒体资料](https://www.stardewvalley.net/press/)，参考其农场题材、像素景观与木质界面的视觉方向。

本项目使用 Tk Canvas 原生图形自行绘制蓝天、云朵、阶梯形山丘、木牌、树木、农舍、幼苗和小鸡。没有下载、截取、分发游戏截图、官方 Logo、角色精灵、贴图或游戏字体。实际界面可离线绘制，不依赖远程图片，也不使用生成式图片资产。

## 视觉系统

- 页面底色 #eee3cb，纸张 #fff7e3，木框 #805231，深色正文 #443125。
- 绿色主操作 #3e6948，与次要木色按钮区分；成功、失败和部分完成均保留可读中文状态。
- 中文使用系统 Microsoft YaHei UI，数字与英文标题使用系统 Segoe UI，不附带字体文件。
- 一套主题覆盖批量工作台、API 设置和单 mod 编辑器。按钮有悬停、按下、焦点与禁用状态。

## 交互与适配

四张统计卡分别展示完整清单的 mod 总数、勾选数、成功数、需要关注数。搜索和筛选不改变勾选；批量操作仍处理所有已勾选项。隐藏的行保留结果更新，重新扫描时完整清除旧行。

窗口按当前屏幕及 DPI 调整。高度不足时缩短景观横幅，进一步折叠统计卡，优先保留清单和开始/停止等操作。长原因在选中行后显示于清单下方，文本按窗口宽度换行。空清单和无匹配结果提供提示。

## 预览与验证

README 预览来自实际程序窗口，目录与名单为虚构演示，无真实 API 请求或游戏写入。文档预览脚本支持 main、small、api 三种视图；单 mod 编辑器也有独立预览脚本。QA 截图保存在被 Git 忽略的 artifacts/qa-*.png 中。

回归覆盖搜索保留选择、全选作用于隐藏项、筛选中的结果更新、重新扫描移除隐藏旧行、最小窗口主按钮可见。批量翻译和安装逻辑保持 0.2.0 行为，数据与备份格式不迁移。
