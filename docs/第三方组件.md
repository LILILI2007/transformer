# 第三方组件与素材

ModLingo 自有源码和原创示例采用仓库根目录 MIT 许可。此许可不改变第三方组件、游戏和 mod 的权利。

运行时源码只导入 Python 标准库。Windows 便携包会包含 Python 解释器、标准库、Tcl/Tk 和打包运行引导，不意味着整包所有文件都采用 MIT。

| 组件 | 用途 | 许可/来源 |
|---|---|---|
| CPython | 运行时解释器和标准库 | PSF 及随附第三方条款；[Python 许可](https://docs.python.org/3/license.html) |
| Tcl/Tk | Tkinter 图形界面运行库 | BSD 风格许可；[Tcl/Tk 许可](https://www.tcl-lang.org/software/tcltk/license.html) |
| PyInstaller 6.16.0 | 构建工具及便携包引导 | GPL 许可带分发例外；[许可说明](https://pyinstaller.org/en/stable/license.html) |
| PyInstaller 依赖 | 构建时分析和封装 | 具体版本见 release/build-environment.txt，各自许可适用 |

仓库没有复制同类翻译工具的源码，也没有打包真实第三方 mod、社区汉化或游戏资产。`examples/` 的名称和句子为此原型自创，其 manifest 仅用于输入测试，不构成完整可加载 mod。

构建脚本收集解释器与打包工具附带的许可文件到便携包 `THIRD_PARTY_NOTICES/`。公开发布前仍需按实际分发内容复核；当前便携版属于本机验证构建，尚未经过代码签名和干净机器兼容验收。

0.3.0 的像素景观和木牌主题由项目代码原创绘制；官方主页和媒体资料仅作视觉参考，不随包分发游戏截图、Logo、角色精灵或字体。
