# 验证记录

## 0.2.0 批量版

本地 Windows x64、Python 3.9.19、Tk 8.6，工作目录含中文。61 项测试：60 项通过，1 项符号链接测试因本机创建权限跳过；Linux CI 将执行该项。源码 GUI 启动检查覆盖单 mod 编辑器与新批量主界面，无 API 调用。

新增验证涵盖：保存路径与多安装识别、Steam 库和自定义安装名、嵌套 mod 扫描及重复身份、默认全选、成功与失败名单、真实写入临时 mod 的中文文件、精确恢复原字节、新文件恢复删除、保留后续玩家修改、损坏备份拒绝、扫描后文件变更拒绝、运行中游戏拒绝、写入失败不损坏原中文、停止、密钥错误停止后续请求、失败批次续跑、更新只重译改动、已有中文复用、旧中文不覆盖新候选、原样英文候选拦截、进程锁和 GUI 队列。

自动测试使用原创临时素材及模拟模型，不证明真实译文语义质量。原版 HTTP 传输测试继续使用本机临时服务，不产生云 API 费用。界面预览名单是演示内容，不是真实扫描或翻译结果。

Windows 便携包通过固定 PyInstaller 构建；构建环境随 release/build-environment.txt 提供。源码、便携 GUI 的启动及 GitHub 云端结果在本次发行时核验。实际发行结果见 [Actions](https://github.com/LILILI2007/transformer/actions)。
