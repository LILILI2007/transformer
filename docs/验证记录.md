# 验证记录

日期：2026-10-15。下面区分工程验证、真实模型验证和游戏内验证。自动检查不等于翻译语义正确或能覆盖全部游戏场景。

## 本地工程验证

环境：Windows x64，Python 3.9.19，Tk 8.6。GUI 和源码位于含中文字符的工作目录。

- 运行 `python -m unittest discover -s tests -v`：36 项测试通过。
- 运行 `python -m modlingo --smoke`：中文界面、示例导入与条目选择检查通过，无网络调用。
- 已生成并目视检查 `artifacts/preview.png`；预览译文由人工填写，不是云模型生成。
- `scripts/make_demo_export.py` 可生成原创人工示例项目及翻译包，7 项译文、2 项复杂语法跳过。示例不是可加载 mod。

| 测试文件 | 覆盖 |
|---|---|
| test_core.py | JSONC、重复键与类型、标记和换行、复杂语法、中文保留、增量、项目往返、导出拦截、路径保护、原文件字节不变 |
| test_provider.py | 接口地址、遮蔽与还原、术语筛选、响应 ID、重试上限、脱敏错误、本机 HTTP 请求 |
| test_gui.py | 手动编辑保存、筛选、再次导入恢复、更新标记、UI 队列写回、重新打开时保留未提交编辑 |
| test_workflow.py | 导入→模拟模型→人工修改→保存重载→更新两项→确认→导出完整循环 |

新增回归覆盖：主动回退不重复调用、空原文更新需确认、非法端口和请求头控制字符拒绝、中途断开的 HTTP 响应有界重试，以及界面的回退筛选与统计。

全流程测试中初版待译 6 项；升级后仅 2 项进入模型队列；未变人工译文保持；变更候选确认前不能导出。模拟模型只用于检验结构和状态机制，不用于证明翻译质量。

## Windows 便携构建

构建脚本：`scripts/build_windows.ps1`；工具版本固定为 PyInstaller 6.16.0。脚本生成 `release/ModLingo-Windows-x64.zip`，实际构建依赖记录在 `release/build-environment.txt`。

已实际完成本机便携 EXE 的 `--smoke` 启动检查，进程退出码为 0。构建路径包含中文，便携包包含运行库和示例素材。已修复 Windows PowerShell 5 对脚本中文路径字面量的编码问题，并调整高分屏窗口尺寸。

尚未在没有 Python 的干净机器或其他 Windows 版本中验收，程序未签名。公开发布前仍应做该环境验证。构建 SHA256 记录在 `release/SHA256SUMS.txt`，属于完整性校验，不等于签名。
